# 紧凑简历页面

2026-10-18

## 视觉设计

网页回到最初开屏的设计方向：暖白背景、大字号职业标题、左文右卡布局和克制的蓝色强调。淡紫渐变与细线圆环只提供空间感，不再使用整块深色背景、巨大 QY 字样或装饰性英文编号。

首屏先呈现姓名、职业定位、简短介绍与两个主要操作；右侧卡片集中展示当前工作和三个专业方向。正文仍只有四段工作经历和两项具体实践。桌面采用经历与实践两栏，手机自动改为单列，当前工作卡片中的三个方向横向排列。

打印页继续使用独立的一页简历排版，不继承网页装饰。所有链接支持键盘操作，移动端触控目标不小于 44px。

验证：360/390/768/1440px 无横向溢出；390px 高约 1639px，1440px 高约 934px；正文仍为两块、四段经历和两项实践。PDF 下载、一页打印、生产构建及桌面和手机截图检查通过。

精简正文保存在 `data/brief.json`，公司、岗位和日期从 `data/resume.json` 读取。Word、ATS、Markdown 使用 `scripts/gen_brief.mjs` 从同一份正文生成；PDF 由 `/print` 页面输出。
