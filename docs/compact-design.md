# 紧凑简历页面

2026-10-18

## 视觉设计补全

设计目标是让简短内容有识别度和阅读秩序。首页采用深墨蓝开屏、暖白正文、蓝紫强调色；姓名与职业定位优先，右侧 QY 轨道图形呼应最初开屏的空间感，不承载业务指标。主要操作是下载一页简历，联系入口紧随其后。

正文仍只有工作经历、两项具体实践。桌面采用左右两栏，经历用细时间线串联，实践用两张低对比卡片呈现；编号、英文小标签与日期建立层级。手机改为单列，轨道退为右上背景，保持文字与操作区域清楚。

开屏只使用轻微入场与轨道运动，内容默认可见；支持减少动态效果偏好，下载和联系入口可键盘操作。打印版沿用简洁的一页排版。

验证：360/390/768/1440px 无横向溢出；390px 高约 1405px，1440px 高 900px；两块正文、四段经历、两项实践未增加。PDF 下载、一页打印与生产构建通过；已查看桌面、手机和打印截图。

首页与打印页共用 components/resume-brief.tsx，精简正文保存在 data/brief.json，公司、岗位和日期仍从 data/resume.json 读取。页面只呈现四段工作经历、两项具体实践、一行常用工具和教育信息。

删除首页原来的独立 AI Lab、能力地图、证明区、成长时间线、统计数字卡及重复项目卡。没有把长文藏进折叠区，直接缩减默认呈现的正文。数字归入其对应公司的经历，删除自评等级、全覆盖、独立负责全流程等笼统或过度表述。

Word、ATS、Markdown 使用 scripts/gen_brief.mjs 从同一份正文生成（需安装 docx 包）；PDF 由 /print 页面输出。旧 gen_docx.py / gen_ats.py 为历史长版生成器，不用于当前简历下载版。
